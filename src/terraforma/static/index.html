        HOW IT WORKS

        Small steps. Real Terraform.

        1. Choose your foundation. Pick a cloud provider, workload, and access settings.
        2. Read your configuration. Preview the three generated files and learn which inputs are required.
        3. Check and download. Validate using your installed tools, then download a ZIP to work with locally.

        Validation checks Terraform structure and lint rules. Review a Terraform plan, costs, and cloud permissions before deployment. This app never applies infrastructure.

        OPTIONAL LOCAL CHECKS

        Set up your validation tools.

        You can generate and download now. Install these tools when you want to check the configuration on this computer.

        1. Terraform reads your configuration and checks resource schemas. Official installation guide ↗
        2. TFLint checks common Terraform mistakes. Official installation guide ↗

        Choose the binary for your operating system and CPU. On Windows, extract both executables into a directory on your user PATH. On macOS/Linux, use the official package-manager or binary instructions.

        Verify in a new terminal:

        terraform -version
tflint --version

        After changing PATH, restart TerraForma so it can see the installed tools. Provider downloads need network access.
